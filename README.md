# Socket Tools на Python

Набор сетевых утилит: сканер портов, баннер-граббер, TCP-сервер и клиент.

## Файлы

| Файл | Описание |
|------|----------|
| `port_scanner.py` | Сканер TCP-портов |
| `banner_grabber.py` | Чтение баннеров сервисов |
| `server.py` | TCP-эхо-сервер |
| `client.py` | TCP-клиент |

## Требования

- Python 3.6+
- Стандартные библиотеки (`socket`, `sys`)

## Запуск

### Сканер портов
```bash
python port_scanner.py 127.0.0.1 1 1024
